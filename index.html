About SafeLAN Talk

🔐 Secure Local Messaging

SafeLAN Talk enables encrypted communication between devices on the same local network without requiring internet access.

📶 Offline LAN Connectivity

Messages flow directly between devices on your Wi-Fi network, keeping your communications local and private.

🧠 Instant Sync & Groups

Real-time messaging with support for group conversations among all users on the same network.

🚀 How It Works

1. Connect devices to same Wi-Fi
2. Open SafeLAN Talk in browser
3. Start chatting securely!
